# Distributed Systems Fundamentals

A collection of distributed systems projects demonstrating core concepts in fault tolerance, consistency, and scalable architecture. Each module builds on the previous, culminating in a full distributed file system with stream processing.

## Projects

| # | Project | Concepts | Status |
|---|---------|----------|--------|
| 1 | [Distributed Grep](DistributedGrep/) | Client-server architecture, parallel querying, socket programming, fault-tolerant aggregation | Complete |
| 2 | Membership Protocol | Failure detection, gossip protocol, heartbeating, group membership | Coming soon |
| 3 | HyDFS (Distributed File System) | Consistent hashing, replication, eventual consistency, re-balancing | Coming soon |
| 4 | Rainstorm (Stream Processing) | Stream processing, operator chaining, exactly-once semantics | Coming soon |

## Architecture Overview

```
┌──────────────────────────────────────────────────────────┐
│                    4. Rainstorm                           │
│              (Stream Processing Engine)                   │
├──────────────────────────────────────────────────────────┤
│                      3. HyDFS                            │
│       (Distributed File System + Consistent Hashing)     │
├──────────────────────────────────────────────────────────┤
│               2. Membership Protocol                     │
│          (Failure Detection + Group Membership)          │
├──────────────────────────────────────────────────────────┤
│                1. Distributed Grep                       │
│         (Parallel Log Querying + Aggregation)            │
└──────────────────────────────────────────────────────────┘
```

Each layer depends on the ones below it. Distributed Grep queries logs generated by the Membership Protocol. HyDFS uses the Membership Protocol for failure detection and ring management. Rainstorm runs on top of HyDFS for persistent storage.

## Getting Started

Each project is self-contained with its own README, runnable locally with no external dependencies (Python 3.6+ only). Start with [Distributed Grep](DistributedGrep/) to see the simplest example.

## Requirements

- Python 3.6+
- No external dependencies (standard library only)
